# Burger na Brasa Rio Preto — MVP em HTML, CSS e JavaScript

Este protótipo é propositalmente simples: não usa React, Vite, Node ou processo de build.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta.
3. Dê dois cliques em `index.html` ou abra-o pelo VS Code com Live Server.

## Arquivos
- `index.html`: estrutura da landing page.
- `style.css`: visual, responsividade e animações CSS.
- `script.js`: menu mobile e animações de entrada com IntersectionObserver.
- `assets/`: logo, foto do lanche e vídeo enviados.

## Antes de apresentar/publicar
- Trocar os links genéricos de WhatsApp e Instagram pelos perfis oficiais.
- Confirmar ingredientes e descrição do Duplo Costela.
- Confirmar horário de funcionamento e cardápio.
- A história desde 2015 e a origem em Barretos foram inseridas conforme as informações fornecidas.
- Endereço inserido conforme confirmação: Rua Saldanha Marinho, 4240, Vila Aurora, São José do Rio Preto – SP.

O projeto é um MVP demonstrativo, sem sistema de pedidos ou painel administrativo.
